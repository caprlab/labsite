# CAPR Lab Website

This repository holds the files for the official Cognitive, Applied, and Perceptual Research (CAPR) Lab website hosted via GitHub Pages at [caprlab.github.io](https://caprlab.github.io).

## 📌 Quick Guide for Lab Members

### Adding a New Team Member
1. Navigate to the `_team/` directory.
2. Create a new file named `firstname-lastname.md`.
3. Fill in the YAML front matter (Name, Role, Bio, Photo name).
4. Upload their headshot to `assets/img/`.
5. Commit and push changes!

### Updating the RA Handbook
1. Open `ra_handbook.md`.
2. Edit the Markdown directly to update lab policies or onboarding procedures.
3. Save and commit. Changes will build live within ~2 minutes.

### Adding Publications
* Add new `.bib` entries directly to `_bibliography/papers.bib`.
